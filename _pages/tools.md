## Hardware

Laptop
: work M1 MacBook Pro

Monitor
: [34 inch Ultragear QHD (3440 x 1440) curved monitor](https://www.amazon.com/dp/B097QF8CP3)

Desktop
: 2022 Discord issued [NZXT BLD PC](https://www.reddit.com/r/NZXT/comments/npkrp2/nzxt_bld_review/). It's been pretty fun. Great CPU and GPU but I've only used it for building Raspberry Pi Pico W software. I compared these build times to Raspberry Pi 4B build times and it was a minute vs an hour.

Desktop GPU
: NVIDIA GeForce RTX 3080

Desktop CPU
: Intel Core i9 11900KF

Nice little KVM to switch between my MacBook and PC
: 

Desktop Mount
: [Eureka Ergonomic under desk mount](https://www.amazon.com/dp/B07MV3GVCK). This thing is cool as hell and it fit perfectly.

Keyboard
: [Ducky One 3 Pure White Hotswap RGB Mechanical Keyboard (Cherry MX Red)](https://www.amazon.com/dp/B09Y2JH9WX). Keys bounce! Don't buy it. It's very fun otherwise.

Mouse
: [Razer DeathAdder V2 Gaming Mouse](https://www.amazon.com/dp/B082G5SPR5). Truly stupid but here we are.

Mesh router
: [ASUS ZenWiFi AX6600 Tri-Band Mesh WiFi 6 System](https://www.amazon.com/dp/B083Q45V1V). I do not recommend it. Wirecutter is wrong. Buggy for my home IoT situation. Reboots are needed too frequently.

DNS
: Pihole on Raspberry Pi 4B
